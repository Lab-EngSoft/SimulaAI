## Fluxo demonstrável

1. O usuário acessa a tela de Login.
2. Um Aluno inicia um simulado no Catálogo de simulados.
3. O Aluno responde às questões e finaliza a tentativa.
4. O sistema mostra o Resultado, incluindo explicações para respostas incorretas.
5. O Aluno consulta o Histórico e o Dashboard.
6. Um Administrador acessa as telas de gestão para manter a base de questões.
